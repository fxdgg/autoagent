# =============================================================================
# This test verifies that when a nested task exhausts its max_attempts,
# the orchestrator correctly marks the task as failed and continues to
# execute subsequent tasks.
#
# Task structure:
#   Task 1: nested (max_attempts=2)
#     - 1.1: simple (succeeds)
#     - 1.2: simple (max_attempts=1, always fails)
#   Task 2: simple (should still execute after task 1 fails)
#
# Expected call sequence (ask() calls in order):
#   Rule 1:  Task 1, Round 1: Subtask 1.1 → ✅ completed
#   Rule 2:  Task 1, Round 1: Subtask 1.2 → ❌ not completed (failure)
#   Rule 3:  Failure analysis → JSON: retry_from=1.2
#   Rule 4:  Task 1, Round 2: Subtask 1.2 (retry) → ❌ not completed (failure again)
#   Rule 5:  Failure analysis → JSON: retry_from=1.2
#            (max_attempts=2 now exhausted, task 1 marked as FAILED)
#   Rule 6:  Task 2 → ✅ completed (executes despite task 1 failure)
#
# Key verification points:
#   - Task 1 should be marked as "failed" after 2 rounds
#   - Task 2 should still execute and complete successfully
#   - The orchestrator should NOT abort on task 1 failure
# =============================================================================
